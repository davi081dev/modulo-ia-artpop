## 1. Visão Geral do Módulo
Este repositório contém o Módulo de Inteligência Artificial para o sistema **ArtPop**, marketplace voltado à valorização do artesanato e da cultura de Pernambuco. O módulo é responsável por recomendar peças artesanais com base na similaridade cultural de tipologia (barro, madeira, tecidos) e polos criativos (Caruaru, Tracunhaém, Petrolina), obras de um mesmo Mestre Artesão, além de prover estratégias de *Cold Start* e *Fallback*.
